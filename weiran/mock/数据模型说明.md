# Mock 数据模型与口径

唯一维护源为 `miniprogram/utils/mock.js`；`mock/students.json` 通过 `node scripts/export-mock.cjs` 导出，含相同学生、字段元数据、等级映射与演示日期。

当前日期固定为 2026-06-29。六名学生均为模拟人物，赛事、导师和资源消息也仅用于演示。

## 基本信息

| 字段 | 来源 | 用途 |
| --- | --- | --- |
| id、name | 模拟教务名册 | 关联学生与本地状态 |
| account、password | 演示账号 | 本地账号校验；不用于正式鉴权 |
| nickname、avatar、avatarColor | 自定义或默认占位 | 头像与昵称展示 |
| mbti | 学生自主填写 | 自述信息展示，不据此诊断或预测成绩 |
| researchInterests | 学生自主填写 | 兴趣匹配推荐 |

默认头像使用昵称首字与颜色占位。新选择的头像先持久保存，再将路径写入资料。

## 画像字段

`FIELD_META` 给出每个画像字段的 label、source、purpose，画像详情页直接读取该字典。

| 维度 | 字段与单位 | 数据来源及用途 |
| --- | --- | --- |
| 学习 | attendanceRate，0–1 比例 | 学期累计出勤，模拟教务签到；用于学习状态 |
| 学习 | homeworkSubmitted / homeworkTotal，次数 | 模拟教学平台；计算作业完成情况 |
| 学习 | homeworkGrade，等级；quizScore，0–100 分 | 模拟作业批改与小测；用于学习掌握情况 |
| 学习 | libraryVisitsFinalMonth，次数 | 当前期末月累计门禁；仅作为行为参考 |
| 身体 | exerciseDaysPerWeek，天；exerciseMinutes，每次分钟数 | 最近 7 天自主填写；用于活动提醒 |
| 身体 | symptoms，症状自述数组 | 自主填写；用于关怀提醒 |
| 身体 | libraryStayHours，近 7 天日均小时数 | 模拟图书馆门禁；时长不等同于学习效率 |
| 身体/心理 | dormInOutTimes，近 7 天进出次数 | 同一模拟门禁来源，两个维度数值必须一致；不能由次数推算离寝时长 |
| 心理 | questionnaireScore，0–20 压力自评分 | 演示问卷，非临床量表；用于关怀，不能作为诊断 |
| 性格兴趣 | mbti、researchInterests | 自主填写；展示与推荐 |

汪同学小测 62 分低于演示学习目标 70 分，文案不再写为低于及格线。所有预警分数和等级仍为预置场景，未把这些示例阈值定义成真实学校标准。

## 预警与观察规则

学业预警包含：

- `id`：预警周期标识。
- `level/value/reason`：预置等级、值、原因。
- `firstNotifiedAt`：首次提醒日期，YYYY-MM-DD。
- `history[]`：每项为 `{ date, value }`，用于日期窗口判断。
- `trend/trendLabels`：原有展示字段；运行时从有效 history 重新生成。

身体与情绪预警保持 `level/value/reason`。

默认观察规则独立存放在 `utils/academic-rules.js`：观察 21 天；近 21 天降幅不足 5% 才升级；允许边界样本最多相差 7 天；不足、过期、非法日期不升级。参考点必须在首次提醒之后，未来数据不参与计算。基线为 0 时不计算相对降幅。

本地运行状态 `wr_academic_runtime_v2` 按学生保存 `warning/asOf/events`。事件字段：id、warningId、studentId、recipient、kind、reason、date、recordedAt、channel、status。学生事件先生成；辅导员事件只是本地待接入记录。

## 通知、反馈与设置

通知类型为 academic、health、emotion、contest、resource；type 决定优先级。topic 可以将健康资源与健康功能开关关联。所有 Mock 消息 ID 唯一。

`wr_notifications_v2` 按学生保存消息与已读状态。统一入口先检查设置再入队，列表与详情再检查一次，防止已存消息绕过关闭开关。

反馈沿用原列表存储，但所有读取/修改按 studentId 过滤。状态为待处理或已处理；学生界面只提交和查看，不自行处理。

`wr_settings_by_student` 按学生保存四个独立开关。旧版无法归属到个人的全局设置不自动迁移，保留原键供排查。个人资料、凭据和处理记录仍使用原来的按学生存储结构。
