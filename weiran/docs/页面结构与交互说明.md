## 主要链路

1. 登录 → 首页查看画像 → 点击学习卡片查看字段来源与用途。
2. 首页切换演示学生 → 对应学生的设置、反馈、个人资料、处理记录分别读取。
3. 学业预警 → 自助/求助/忽略 → 持久保存操作记录；自助打开计划草稿，确认后创建；求助额外生成本地辅导员待处理事件。
4. 学业预警 → 模拟时间推进 → 真实比较日期窗口与数值降幅 → 条件满足时生成去重的升级事件。
5. 设置关闭显示 → 返回首页/画像详情/每日记录/周报，对应字段、统计、解释均隐藏，修改学习数据保留隐藏字段。
6. 设置关闭预警功能 → 消息列表与直接打开的详情均隐藏，新同类消息不入队。
7. 个人中心 → 数据反馈 → 提交 → 自己的反馈中显示“待处理”。
8. 个人中心 → 设置 → 头像昵称 → 保存 → 返回页面同步更新。
9. 计划 → 完成/延期/取消任务 → 刷新执行统计；每日记录 → 修改/补记 → 周报立即使用当前版本统计。
10. 三个成长页可推进模拟日期一天，观察到期、逾期、窗口移动和数据不足，不自动补造成绩或记录。

## 预警事件与展示边界

学生首次提醒和辅导员待处理事件分别保存。模拟日期与电脑时间区分：事件包含模拟发生日期及实际记录时间。相同预警周期、相同升级原因只产生一条事件；多次学生选择仍逐次保留操作记录。

“重播首次提醒”只清空当前学生的预警模拟历史与处理记录，需在界面确认；不影响其他学生、账号或资料。
成长模块复用此模拟日期。重播后未来创建的计划、未来记录暂不展示，已创建计划的完成/延期按当时已发生日志投影；未来已有同源计划时拒绝再次创建，需推进到原日期查看。成长记录不因重播被删除。

当前初始日期为 2026-06-29。固定历史在默认状态下已有明显下降；推进一周并保持不变可演示升级。原有评分、分级仍为本地 Mock，观察规则仅判断何时升级。

## 辅导员网页

登录页和主框架互斥显示。五个导航页面分别为总览、学生列表、学生详情、学业预警管理、数据反馈管理。各页业务内容为空，符合本阶段范围。

后续通过 `getCounselorEvents(studentId)` 的数据结构定义接口，再接入共享服务。微信本地存储与浏览器存储不会自动互通，当前网页不声称已接收到小程序事件。
