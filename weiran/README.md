# 未然 · 高校学生画像与预警平台 MVP

原生微信小程序 + 辅导员网页空框架，使用前端本地 Mock 数据。画像以学习状态为主，消息按学业、健康、情绪、赛事、资源排序。

## 运行学生端

1. 使用微信开发者工具导入仓库根目录（包含根目录 `project.config.json`）。也可导入 `weiran/miniprogram`；两个入口的 AppID 和基础库版本现已统一。
2. 配置保留了原来根目录的 AppID。如果你没有该 AppID 的开发权限，在工具中选择你自己的测试号 AppID。项目没有预先配置 `touristappid`；请勿把仓库 AppID 当作通用测试号。
3. 当前配置的基础库为 3.17.3。无需安装 npm 包、无需后端、无需构建步骤。
4. 编译后在登录页选择学生，点击“本地模拟登录”。或使用账号密码登录。
5. “微信登录体验”调用 `wx.login`，成功后仍映射到所选模拟学生。它没有接入服务端会话交换或学籍绑定，不是正式身份认证。接口不可用时会提示使用本地模拟登录，不会默默切换身份。

## 运行辅导员端

直接用浏览器打开 `counselor-web/index.html`。登录页点击“进入系统”，可切换总览、学生列表、学生详情、学业预警管理、数据反馈管理，再退出登录。

按 MVP 范围保留空框架，没有实际辅导员账号验证和业务数据。小程序的本地事件不会自动跨浏览器同步。

## 预警流程如何演示

所有日期是固定的模拟日期，初始为 2026-06-29，不使用电脑当前日期自动推进。

1. 登录汪同学，从首页或消息中心进入预警详情。
2. 默认历史为 72 → 68 → 65 → 63 → 62，对应 06-01、06-08、06-15、06-22、06-29。近 21 天是 68 → 62，降幅约 8.8%，初始不自动升级。
3. 点击“7 天后 · 数值不变”，日期推进至 07-06；近 21 天为 65 → 62，降幅约 4.6%，生成一条辅导员待处理事件。
4. 反复进入详情不会重复生成同一周期、同一原因的事件。
5. 点击“重播首次提醒”，确认后回到 06-01。连续两次推进 7 天仍处于观察期；第三次无改善推进才会触发自动升级。
6. “请求辅导员帮助”不等待观察期，立即生成本地待处理事件；“自助处理”和“忽略”只记录选择，观察仍继续。每次选择均保存处理记录。
7. “7 天后 · 下降 10 分”可以演示明显改善；数值降到 0 时结束当前预警。已产生的事件作为历史记录保留。

事件含学生 ID、预警周期 ID、接收方、原因、模拟发生日期、实际记录时间和状态。辅导员事件状态是“待接入辅导员服务”，不表示已发送微信订阅消息。

`utils/academic-rules.js` 管理观察期和降幅判定：默认观察 21 天，降幅不足 5% 升级，边界恰好 5% 不升级；数据缺失、过期或日期无效时不自动升级。它不负责计算学业预警分数和等级，这部分仍使用 Mock，供分工 ① 后续接入。

## 设置、反馈与资料

- 设置按学生保存。关闭身体/心理显示后，首页和画像详情隐藏对应模块。
- 关闭健康/情绪预警后，对应消息、详情与关联健康资源隐藏，新通知入口也拒绝该类型入队；首页的相关徽标显示“预警已关闭”。数据模块是否可见由单独的显示开关控制。
- 再开启时可查看原有消息；关闭期间通过通知接口投递而被拒绝的消息不会补发。
- 反馈只显示当前学生自己的记录；可以提交错误或缺失数据，默认状态为待处理。保留状态更新函数，学生页面不能自行标记已处理。
- 头像通过文件系统保存为持久缓存路径，成功替换后清理旧头像；失败会保留原头像。昵称最长 20 个字符。
- 学生页面统一检查登录状态；退出后不会自动变成黄同学。
- 当前数据只保存在本机，清空微信开发者工具存储会重置演示数据。

旧版数据：账号密码、资料、反馈和操作记录沿用原存储键；旧版全局设置无法可靠判断属于哪个学生，因此保留旧键但不复用，新版各学生设置从默认值开始。升级后需重新登录一次，避免把旧版自动设置的账号当作有效会话。

## 数据与目录

```
weiran/
  miniprogram/
    utils/mock.js             唯一维护的 Mock 源及字段来源/用途
    utils/store.js            本地状态、账号隔离、通知、反馈、事件
    utils/academic-rules.js    按日期判断观察期与升级
    utils/page.js             学生页面登录守卫
    pages/                    14 个页面，含设置子页和消息详情
  counselor-web/              登录 + 5 个业务页面空框架
  mock/students.json          从 mock.js 导出的交付数据
  scripts/export-mock.cjs     同步 JSON 数据
  scripts/check-wechat-templates.cjs
  tests/mvp.test.cjs          业务回归测试
  docs/
    页面结构与交互说明.md
    修复与验收记录.md
    第4部分-功能拓展与计算方案.md
```

修改 `miniprogram/utils/mock.js` 后，在 `weiran` 目录运行：

```text
node scripts/export-mock.cjs
```

不要分别手改 JS 与 JSON，避免两份数据漂移。身体与心理维度使用同一时间窗的寝室出入次数；所有问卷、赛事与资源均为演示数据。字段具体口径见 `mock/数据模型说明.md`。
